# Python Dragon Adventure Game

## About This Project
This is a text-based adventure game I created while learning Python in my programming course. The game allows players to explore different rooms by typing commands.

This project helped me practice writing Python code and understand how different parts of a program work together.

## How to Play
1. Run the `move_between_rooms.py` file using Python.
2. The game starts in the Great Hall.
3. Enter commands such as `go north`, `go south`, `go east`, or `go west` to explore.
4. Type `exit` when you want to stop playing.
